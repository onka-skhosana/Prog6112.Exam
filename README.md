# Java Exam Projects - 2026

This repository contains the complete source code and unit tests for the practical Java exam, organized into two separate projects.

---

## 📁 Question 1: Mattress Sales Report Application
A console-based Java application that tracks and summarizes 3-month mattress sales using single and two-dimensional arrays.

* **Features:**
  * Interface implementation (`IProduct`)
  * Array-based sales storage and processing (`Product`)
  * Dedicated report printer class (`PrintProduct`)
  * JUnit unit tests for total and average sales calculations

---

## 📁 Question 2: Mattress Sales GUI Application
A Java Swing GUI application designed to capture customer orders, calculate VAT and commission, display results, and log records to a text file.

* **Features:**
  * Interface implementation (`IProductCalculations`)
  * Calculation logic (`ProductCalculations`)
  * Pure-code Swing GUI window with File and Edit menus (`ProductApp`)
  * File persistence (`data.txt` logging)
  * JUnit unit tests for VAT and total calculations
